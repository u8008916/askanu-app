# Brand assets

Only brand files with confirmed permission belong in this directory. The App
discovers supported SVG, PNG and WebP files at build time through
`src/ui/brandAssets.ts`.

| File (svg, png or webp)        | Used for |
| ------------------------------ | -------- |
| `anu-crest.*`                  | Header crest |
| `anu-crest-dark.*` (optional)  | Dark-theme crest |
| `anuhub.*`                     | Quick Link: AnuHub |
| `mytimetable.*` (optional)     | Quick Link: MyTimetable |
| `canvas.*`                     | Quick Link: Canvas |
| `anu-careers.*` (optional)     | Quick Link: ANU Careers |

Missing brand assets use the App's generic placeholder marks and icons.

Status (6 Oct 2026): no ANU logo or crest is bundled. The horizontal ANU logo
previously sourced from the official ANU Imagebank has been removed while
explicit permission for use is being confirmed. Until approval is received,
the AskANU header uses the generic shield placeholder.
